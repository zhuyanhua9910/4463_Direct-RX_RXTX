## 本次落地：上电休眠（Si4463 SLEEP，MCU 不休眠）
用户确认的方案：**上电就睡、按键进模式、断电才复位**（不做长按回休眠、MCU 不进 STOP）。

改动：
- `Core/Wf4464/Src/wf4463_app.c` + `.h`：新增
  - `wf4463_sleep()`：清挂起中断 → CHANGE_STATE(READY) → PollCTS → CHANGE_STATE(SLEEP)
  - `wf4463_wake()`：ClearCTS → dummy `request_device_state` → PollCTS 重试(0xFF) → CHANGE_STATE(READY)
- `Core/Src/main.c`：
  - 模式枚举改为 `MODE_IDLE=0 / MODE_RAW_RX=1 / MODE_PACKET=2`，`g_mode` 初值 IDLE
  - 上电 `wf4463_init()` → diag → `wf4463_sleep()`，LED 灭
  - `Mode_Update()` 增加 IDLE 分支（直接 return，不跑 diag）与”从 IDLE 出来先 wake”
  - 主循环 IDLE 时 `continue`（避免任何 SPI 唤醒芯片）
- 编译通过：text 22120 / data 156 / bss 2212。

关键认知（写进代码注释）：
1. **SLEEP 下任何 SPI 事务都会唤醒芯片** → 休眠期间不能调 device_state/diag/rssi。
2. SLEEP 后第一条 SPI 命令会被吞 → 必须发 dummy。
3. CHANGE_STATE 命令码是 **0x34**（不是 0x36），SLEEP 参数 = 0x01。
4. 待机电流预期：MCU ~20 mA + 芯片几十 µA ≈ 20 mA（MCU 是大头，若要 mA 级需降主频或 STOP）。
