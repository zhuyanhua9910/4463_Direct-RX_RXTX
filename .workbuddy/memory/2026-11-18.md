# 2026-11-18

## STM32F103C8T6_WF_DEMO 增加按键 S2/S3

- 硬件：S2 -> PB6，S3 -> PB7，按下为低电平（低有效），配置为 GPIO_MODE_INPUT + GPIO_PULLUP。
- 改动文件：
  - `Core/Inc/main.h`：USER CODE Private defines 里加 S2_Pin/S2_GPIO_Port(PB6)、S3_Pin/S3_GPIO_Port(PB7)。
  - `Core/Src/gpio.c`：MX_GPIO_Init() 中把 PB6|PB7 配成输入上拉。
  - `Core/Src/main.c`：KEY_NUM/KEY_DEBOUNCE_MS/KEY_DOWN/KEY_UP 宏、`Key_t` 结构体、`s_keys[]` 表、`Key_Scan()`（20ms 定时消抖 + 边沿触发 printf），在 while(1) 开头调用，TX/RX 两种角色都会扫描；上电还打印一次按键空闲电平自检。
  - `STM32F103C8T6_4463.ioc`：补上 PB6=S2 / PB7=S3（GPIO_Input + PullUp，PinsNb 12->14），保证 CubeMX 重新生成不回退。
- 编译验证：arm-none-eabi-gcc 12.3.1 (CubeCLT) + CubeIDE 自带 make，Debug 目录 make all 通过。仅存在原有 `snprintf("%03u")` 截断警告，与本次改动无关。
- 已知特性：主循环 TX 分支等待 ACK 最长 100ms、RX 分支 rx_fetch 超时 50ms，属阻塞调用，按键响应最坏延迟约 50~150ms；如需毫秒级响应应改为 EXTI 中断或状态机非阻塞。
